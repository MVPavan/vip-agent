# Coding style

The language and stack for vip-agent are not chosen yet. Add code rules here
once they are; until then only the written-records rules apply.

## Written records

- Match the surrounding Markdown: dense prose, tables for comparisons, short
  sections, no filler.
- Cite repo-relative paths; mark parent-repo paths as such
  (`.repo-context/repo-map.md`).
- Label claims as checked, reported, inferred or UNVERIFIED; date vendor
  facts that change.
- Record decisions in the design record (`docs/`) with owner and date; keep
  `.repo-context/` files as routing and summaries that cite their source.
- Experiments go in `scratchpad/`.
