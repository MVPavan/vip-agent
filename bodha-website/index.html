Bodha  ·  Cognitive memory for AI agents

Learn. Consolidate. Forget.

Bodha is a cognitive memory system for AI agents, inspired by Patañjali's Yoga Sūtras and the Sāṅkhya model of mind, informed by modern neuroscience, so agents remember what matters, learn the patterns behind it, correct what has changed, and let go of what no longer holds.

01  The problem

Agents have storage, not memory.

Storing is easy. Memory takes discernment: it weighs, revises, learns, and lets go.

  • i.Amnesia. Without lasting memory, sessions start from zero or the same static context. Users or harnesses repeat themselves.
  • ii.Hoarding. Agents that store everything slowly fill with stale and contradictory memories, and recall them with equal confidence.
  • iii.No evidence. When an agent "remembers" something, there is rarely a way to see where it came from, or to correct it.
  • iv.No learning. Memories are recalled; patterns are not learned. Day one hundred works like day one.
02  The insight

Two lenses, one pattern.

Sāṅkhya-Yoga maps the mind as a set of faculties with distinct authority.
Modern neuroscience offers another lens on the same question: how experience becomes lasting memory.

03  The mind-stack · अन्तःकरण

The mind-stack, rebuilt for agents.

Sāṅkhya calls the mind the antaḥkaraṇa, the inner instrument. Bodha envisions it as a mind-stack.
Each faculty becomes a component with one job and one boundary. Select a faculty, or follow a flow.

04  What Bodha remembers

Every kind of memory, on both sides of the relationship.

Bodha's vision spans the full range of memory: about the people an agent works with, and about the agent's own work.

05  The life of a memory

From a passing remark to a lasting tendency.

Experience leaves impressions; repetition turns them into tendencies. The Yoga Sūtras call them saṁskāras and vāsanās.
Bodha calls it personalisation.
