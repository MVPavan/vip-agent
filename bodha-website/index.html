01  The problem

Agents have storage, not memory.

Storing is easy. Memory takes discernment: it weighs, revises, learns, and lets go.

  • i.Amnesia. Every session starts from zero, or the same static context. Users or harnesses repeat themselves. Nothing carries over.
  • ii.Hoarding. Agents that store everything slowly fill with stale and contradictory memories, and recall them with equal confidence.
  • iii.No evidence. When an agent "remembers" something, there is rarely a way to see where it came from, or to correct it.
  • iv.No learning. Memories are recalled; patterns are not learned. Day one hundred works like day one.
02  The insight

Two lenses, one pattern.

Sāṅkhya-Yoga maps the mind as a set of faculties with distinct authority. Read as a systems architecture, it says something modern neuroscience agrees with.

03  The mind-stack · अन्तःकरण

The mind-stack, rebuilt for agents.

Sāṅkhya calls the mind the antaḥkaraṇa, the inner instrument. Bodha envisions it as a mind-stack. Each faculty becomes a component with one job and one boundary. Select a faculty, or follow a flow.

05  Sūtras · सूत्र

Six threads the system is strung on.

A sūtra is a thread — a short rule meant to be held. These are Bodha's, enforced as invariants in code wherever they are live.

I.

Nothing is remembered without evidence.

Every memory carries the verbatim words it came from, and the turn they were spoken in.

Live
II.

Reasoning decides; the substrate holds.

No model runs inside the commit to the memory substrate. The substrate never chooses what to keep.

Live
III.

Correction is not deletion.

When something changes, the old memory is retired with its history intact, and every correction is logged.

Live
IV.

One mind's memory is never another's.

Memories are bound to the person they are about, even in a shared pool.

Live
V.

The self is given; habits are earned.

Ahaṅkāra — the agent's identity — is read-only. Vāsanā — its tendencies — is learned, and capped in influence.

In development
VI.

Rest is part of remembering.

Dhāraṇā works while the agent is idle: consolidating, reconciling, and letting go.

In development
