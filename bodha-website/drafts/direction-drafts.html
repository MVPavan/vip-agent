1 · What strong memory-company sites do

Read today: Mem0, Letta, Zep, Supermemory. Each has one idea worth borrowing.

LettaManifesto + research cards"Machines that learn." Short thesis, then dated research cards (MemGPT, Sleep-time Compute). Reads like a lab, not a vendor.
SupermemoryThesis, then "Figure 1"An argument up top, then a numbered architecture figure (inputs → learner → memory → agent). Treats the site like a paper.
ZepClassical art + one great diagram19th-century paintings as section bands; a knowledge-graph figure with an "UNTIL MAR 2026" tag showing facts that expire.
Mem0Three verbs"Add → Learn → Retrieve." The whole system in three words, plus a copyable code sample.

For Bodha: Letta's manifesto tone + Supermemory's numbered figures + Zep's classical imagery — but with Indian manuscript aesthetics instead of Western paintings. None of the four has a philosophical origin story; that is Bodha's unclaimed ground.
